## Features

- **Employee CRUD Operations**
  - Create, get, edit, and delete employees.
- **Image Upload**
  - Upload and display employee profile images.
- **Custom Layouts**
  - Separate layouts for the main application and authentication pages.
- **Cookie-Based Theme**
  - Store the selected theme (White/Black) using Cookies.
- **Session Management**
  - Serialize an employee and store it in Session, then retrieve and display it.
- **Middleware**
  - Implemented inline `Use`, `Map`, and `Run` middleware to demonstrate ASP.NET Core request pipelines.
- **ASP.NET Core Identity**
  - User registration, login, authentication, and logout using Identity.
